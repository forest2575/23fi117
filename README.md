# Three.js 花火CG作品

## 概要
TypeScriptとThree.jsを用いて、夜の都会の街並みに花火が打ちあがるシーンを制作しました。ユーザの操作によって視点をズームアウトすると、都市から地球、さらに宇宙空間へとスケールが変化する構成とし、空間の広がりを感じられる演出を行いました。

〇都市のシーン
複数のジオメトリ（Cylinder / Box / Sphere など）を組み合わせて建物や樹木を作成し、配置をランダム化することで自然な街並みになるよう工夫しました。

〇花火のアニメーション
打ち上げと爆発の処理を分けて実装し、パーティクル表現や透明度の変化を用いることで、花火が広がり消えていく様子を表現しました。時間制御にはTHREE.Clockを使用し、動きの自然さを調整しました。

〇宇宙空間の表現
ズームアウトに応じて地球や天体が見えるよう配置を調整し、背景には多数の点を配置して星空を表現しました。さらに回転や明滅の動きを加えることで、よりリアルな宇宙空間になるよう工夫しました。


## 技術
- TypeScript
- Three.js
